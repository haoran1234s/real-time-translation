# TransForge — 1:1 屏幕实时原位翻译 (iOS & PC 双端通用版)

> 融合 `yeshengliu/OnscreenTranslator`（iOS 快捷指令 1:1 原位覆盖）、`mapple2/-Android`（OCR 坐标提取 + 百度/腾讯/Google 异步翻译 + 原位卡片覆盖）与 `VoxGo`（PC + 手机局域网实时协同）核心优点的精简双端实时屏幕翻译系统。

---

## 一、 核心特性

1. **1:1 原位覆盖替换 & `T1~Tn` 框选标注双模式**：
   - **1:1 原位覆盖模式**：自动采样原文字周边的真实背景主色与高对比度文字色（符合 WCAG $\ge 4.5:1$ 标准），就地覆盖原文并支持点击任意卡片独立切换「译文 / 原文」。
   - **`T1~Tn` 框选标注模式**：在原画面上绘制精准翡翠绿坐标框与角标，与右侧双语对照流双向高亮联动。
   - **按住对照原图**：按住「按住对照原图」按钮立即 0 延迟透视底层原图。
2. **iOS 手机端「轻点背面两下」1 秒原位汉化（免越狱、免 Xcode 7 天重签）**：
   - 提供专属极速直出端点 `POST /api/ios-shortcut`，配合 iPhone 自带「快捷指令（截屏 $\rightarrow$ 发送至接口 $\rightarrow$ 快速查看 Quick Look）」，在任何外文 App、推文、漫画或商品页敲两下手机背面，1 秒直接全屏弹出 1:1 原位汉化图，下拉即回原 App。
3. **电脑 + 手机双端实时同步**：
   - 支持电脑端一键截取当前屏幕（`POST /api/capture-pc`）、全局 `Ctrl + V` 粘贴截图；
   - 当手机端通过快捷指令触发截屏翻译时，电脑端工作台自动同步展现最新翻译画面与双语文本。
4. **三大高速机器翻译引擎（整屏单次合并请求）**：
   - **Google 极速免配置引擎**（默认内置，0 配置开箱即用）；
   - **百度翻译通用 API**（MD5 签名，将整屏多段文字合并为单次 `\n` 请求，耗时 ~200ms）；
   - **腾讯云机器翻译 TMT**（`TC3-HMAC-SHA256` 标准签名，支持 `TextTranslateBatch` 批量接口）。

## 二、 快速启动

双击运行根目录下的 **`start.bat`**，或在终端执行：

```bash
cd e:\projects\real-time-translation\server
python main.py
```

启动后浏览器访问：`http://localhost:8765`（手机在同一 Wi-Fi 下访问顶部「iOS 轻点背面配置」弹窗中显示的局域网地址）。
